# 1-first-repository

This repository introduces the basic Git workflow.

## Objectives

* Create a repository from a template
* Clone a repository
* Edit a file
* Save your changes
* Commit your changes
* Push your commit to GitHub

## Files

* `your-name.py`

## Task

1. Create your own repository from this template.
2. Clone your repository to your computer.
3. Open `your-name.py`.
4. Replace the placeholder with your name.
5. Save the file.
6. Commit your changes.
7. Push your commit to GitHub.

By the end of this exercise, you will have completed your first Git workflow:

**Edit → Commit → Push**
